# 📂 Projetos em Destaque

## 📱 ResolveAI

Aplicativo mobile desenvolvido em grupo para conectar clientes e profissionais de serviços utilizando geolocalização em tempo real.

### Tecnologias utilizadas

- React Native
- Expo
- JavaScript
- React Context API
- Supabase
- PostgreSQL
- Google Maps API
- Supabase Authentication
- Supabase Realtime
- Storage Buckets
- Row Level Security (RLS)

### Funcionalidades

✔️ Login e Cadastro

✔️ Geolocalização

✔️ Busca de profissionais próximos

✔️ Chat em tempo real

✔️ Atualização da localização

✔️ Solicitação de serviços

✔️ Avaliações e comentários

✔️ Cobrança do serviço

🔗 **Repositório:**

https://github.com/Juii-Cesar/App_mobile-ResolveAi
